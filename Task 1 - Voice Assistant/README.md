#`OIBSP/PYTHON-TASK1-VOICEASSISTANT/`

A Python voice assistant built for the Oasis Infobyte Python Programming Internship.

## Features
- Greets the user
- Tells the current time and date
- Searches the web by voice
- Asks you to repeat when speech is not understood
- Stops when you say "bye"

## Libraries
SpeechRecognition, pyttsx3, PyAudio, datetime, webbrowser

## How to run
1. Install the libraries: `python -m pip install -r requirements.txt`
2. Run: `python voice_assistant.py`
3. Speak commands like "hello", "what is the time", "search python tutorials"

Needs a microphone and an internet connection.
